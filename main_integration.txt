1. USER CODE BEGIN Includes 區域加入：

#include "encoder_test.h"

2. USER CODE BEGIN 2 區域加入：
   此位置必須在 MX_TIM2_Init()、MX_TIM3_Init()、MX_TIM4_Init()、MX_TIM5_Init() 之後。

if (EncoderTest_Init() != HAL_OK)
{
    Error_Handler();
}

3. 在既有 while (1) 的 USER CODE BEGIN 3 區域加入：

EncoderTest_Update();
